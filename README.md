# Restaurant Management System in C

## Project Overview
This is a simple Restaurant Management System developed using C programming. The program allows customers to select food items, enter quantities, and generate a final bill with discount and GST.

## Features
- Enter customer name
- Display restaurant food menu
- Select food items and quantities
- Calculate total bill
- Apply 10% discount on orders of Rs. 500 or more
- Calculate 5% GST after discount
- Generate final bill

## How to Run

**Step 1:** Save the program as `restaurant_management.c`.

**Step 2:** Compile using GCC:

`gcc restaurant_management.c -o restaurant_management`

**Step 3:** Run the program:

Windows:

`.\restaurant_management.exe`

Mac/Linux:

`./restaurant_management`
